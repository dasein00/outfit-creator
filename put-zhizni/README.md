# Путь жизни — Android-приложение

Персональная система организации жизни по техническому заданию PRIME ERA:
день, состояние, активность, питание, тренировки, деньги, привычки, обучение,
культура, хобби и долгосрочные цели в одной базе. AI-помощника нет, работает офлайн.

## Как установить на телефон

1. Откройте на телефоне страницу релиза **«Путь жизни — последняя сборка»**
   (`Releases → put-zhizni-latest`) или артефакт `put-zhizni-apk` в GitHub Actions.
2. Скачайте `put-zhizni.apk` и откройте его. Android попросит разрешить установку
   из этого источника — разрешите.
3. При первом запуске уже есть расписание недели, привычки и ценности из планера.
   Их можно поменять в разделах «План», «Привычки» и «Настройки → Профиль».

Обновления ставятся поверх старой версии без потери данных: все сборки подписаны
одним ключом `app/putzhizni.jks`.

| Раздел | Возможности |
|---|---|
| Сегодня | карточки дня (порядок и видимость настраиваются): главное дело, настроение/энергия/стресс/тревожность, расписание, привычки, задачи, вода, сон, шаги, погода, КБЖУ, тренировка, чтение и пианино с таймером, карта дня, финансы, напоминания, вечерняя сверка «план → факт → препятствие» |
| План | день (шкала времени, обязательные и желательные дела), неделя (сетка как в бумажном планере, главное дело недели, воскресный протокол, приоритеты, правила, перенос незавершённого, % выполнения), месяц (календарь и цветовая карта любого показателя) |
| Задачи, идеи | формула «глагол + объект + объём + срок», минимальная версия, повторы, контейнер идей с экспериментом на 1–3 дня |
| Привычки | периодичность, дни недели, минимальная цель, напоминание, серия, план/факт, статусы «выполнено / частично / пропуск / не планировалось», баллы и награды по желанию |
| Трекеры | годовые матрицы 1–31 × месяцы: настроение, погода, температура, шаги, сон, стресс, тревожность, энергия, тренировки, вода, привычки, чтение, питание; легенда, символы, печать |
| Здоровье | сон, шаги (датчик телефона или вручную), вода, состояние, температура тела, погода (Open-Meteo, при отсутствии интернета — последнее значение и ручной ввод); графики 7/30/90/365 дней |
| Питание | база продуктов, приёмы пищи, цели КБЖУ, план/факт, статистика |
| Тренировки | типы, подходы, повторения, вес, расстояние, темп, библиотека упражнений, графики частоты, длительности и объёма |
| Финансы | счета, доходы, расходы, переводы, бюджеты по категориям, цели накоплений, регулярные платежи (авто-запись или напоминание), финплан месяца |
| Обучение | курс пианино из 21 урока с клавиатурой, тренажёром нот и метрономом; Таро (78 карт, уроки, карточки Лейтнера, тесты, карта дня, журнал раскладов); Кету (справочник, 27 накшатр, даши, карточки, расчёт среднего узла); Бацзы (стволы, ветви, элементы, Десять Богов, карточки); книга PRIME ERA с протоколами |
| Нумерология и Бацзы | встроенный модуль расчёта (ваш файл «Усовершенствованная нумерология») |
| Цели | горизонты 10 лет → день, этапы, связанные привычки и задачи, ценности, программа 90 дней, рефлексия месяца, колесо жизни, годовые вопросы |
| Статистика | неделя, месяц в одном экране, год на одной странице, сравнительный анализ (корреляции с нейтральными формулировками), PRIME SCORE с формулой и весами |
| Настройки | профиль и режим, цели, светлая/тёмная тема, акцентные цвета, уведомления по типам, PIN и биометрия, экспорт JSON/CSV, PDF через печать, восстановление, ежедневные автокопии, полное удаление |

## Версия 2.0

- Главная: приветствие, статистика дня с полосой прогресса, недельный график веса со стрелкой тренда, 5 задач, сменяющиеся факты о достижениях и факты о приметах, эзотерике, ведах и алхимии; каждая метрика открывает свой раздел.
- Трекеры: нажатие на клетку открывает ввод прямо в трекере.
- Задачи и проекты (папки с цветом), подзадачи, теги, архив, сортировка. Привычки с числовой целью. Цели с целевым значением и темпом.
- Здоровье: профиль тела и расчёт КБЖУ, вес с прогнозом, замеры, фото прогресса, сон (звёзды, заметки, автоопределение), настроение несколько раз в день, колесо баланса.
- Рецепты и меню: каталог, редактор с фото, меню недели, шаблоны, повторяющиеся блюда, список покупок, история готовки.
- Финансы: категории, общий бюджет с предупреждениями, отчёты, импорт из текста/CSV/JSON и SMS от 900.
- Обучение: рок-песни на пианино с аккордами, иллюстрации Таро Райдера — Уэйта, английский и латынь.
- Android: Health Connect, виджет на главный экран, переходы из уведомлений, сворачиваемые блоки.

## Данные

- Хранятся только на телефоне: `localStorage` WebView плюс копия в памяти приложения
  (`files/backup/current.json` и ежедневные копии за 14 дней).
- В интернет уходит только запрос погоды по координатам выбранного города.
- Фото хранятся в памяти приложения (`files/photos`) и не входят в JSON-копию.
- Иллюстрации Таро — колода Райдера — Уэйта (рисунки П. К. Смит, 1909), общественное достояние.

## Устройство проекта

```
put-zhizni/
  app/src/main/java/ru/putzhizni/app/   Kotlin: WebView, мост к JS, напоминания, шаги
  app/src/main/assets/www/              интерфейс (HTML/CSS/JS, без внешних библиотек)
    js/core.js        хранилище, навигация, формы
    js/data.js        модель данных, показатели, PRIME SCORE, корреляции
    js/v-*.js         экраны
    js/content-*.js   учебные материалы и книга
    numerology.html   модуль нумерологии и Бацзы
```

Сборка: `./gradlew assembleRelease` (нужны JDK 17 и Android SDK 34), либо
автоматически в GitHub Actions при каждом изменении папки `put-zhizni/`.

Интерфейс можно открыть и в браузере: `app/src/main/assets/www/index.html`
через любой локальный веб-сервер.
