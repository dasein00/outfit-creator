# Путь жизни — Android-приложение

Персональная система организации жизни по техническому заданию PRIME ERA:
день, состояние, активность, питание, тренировки, деньги, привычки, обучение,
культура, хобби и долгосрочные цели в одной базе. AI-помощника нет, работает офлайн.

## Как установить на телефон

1. Откройте на телефоне страницу релиза **«Путь жизни — последняя сборка»**
   (`Releases → put-zhizni-latest`) или артефакт `put-zhizni-apk` в GitHub Actions.
2. Скачайте `put-zhizni.apk` и откройте его. Android попросит разрешить установку
   из этого источника — разрешите.
3. При первом запуске уже есть расписание недели, привычки и ценности из планера.
   Их можно поменять в разделах «План», «Привычки» и «Настройки → Профиль».

Обновления ставятся поверх старой версии без потери данных: все сборки подписаны
одним ключом `app/putzhizni.jks`.

Бесплатные модели выбираются автоматически, при перегрузке — следующая. Ключ хранится только на телефоне и не попадает в резервные копии. Отдельный экран чата.
- **Расклады Таро и Ленорман:** Таро Уэйта (одна карта, три карты, да/нет, отношения, выбор, Кельтский крест) и Ленорман (линии 3 и 5, квадрат 3×3, Большой расклад 36). Карты — случайно, вручную или **по фото**: ИИ распознаёт карты и порядок, ошибки можно поправить. Значения по позициям без интернета и ИИ-толкование по выбранной системе, включая «Мой метод» — свой конспект книг. Журнал раскладов.
- **Сбербанк / SMS 900:** распознаются SMS, где номер записан как «СберБанк 900», и сообщения в стиле переписки (Google Сообщения, Samsung); журнал «Что пришло от банка»; перезапуск службы; ручная вставка текста SMS.
- **Пианино:** путеводитель по кнопкам вашего цифрового пианино (TONE, DUAL, SPLIT, BEAT, TEMPO, RHYTHM, CHORD, SYNCH, REC/PLAY, SETTING…), фишки и план занятия; курс расширен до 33 уроков (аккорды поп-музыки, арпеджио, ритмические рисунки, чтение с листа, подбор по слуху, импровизация, блюз, фразировка); звучащие примеры и советы «на вашем пианино» к урокам; урок дня на карточке.
- **Мини-гримуар:** Луна сегодня (фаза, освещённость, лунный день, знак — без интернета), календарь фаз, Колесо года, дни недели, свечи, камни, травы (с пометками безопасности), стихии, 24 руны и руна дня, 10 ритуалов, Книга теней. Карточка «Луна сегодня» на главной.
- **Нумерология по книге «Числа Судьбы» (А. Костенко):** новые разделы «Пифагорейская система» (Сердце, Личность, Судьба, Рождение, мастер-числа 11 и 22, предупреждающие числа, связи чисел, урок года) и «Девять звёзд» (звезда года и месяца). Каждая система подписана и считается по своим правилам.

## Данные

- Хранятся только на телефоне: `localStorage` WebView плюс копия в памяти приложения
  (`files/backup/current.json` и ежедневные копии за 14 дней).
- В интернет уходит только запрос погоды по координатам выбранного города и — по кнопке в переводчике — однократное скачивание модели перевода ML Kit; запросы к ИИ (только если вы добавили ключ OpenRouter) уходят на openrouter.ai.
- Фото хранятся в памяти приложения (`files/photos`) и не входят в JSON-копию.
- Иллюстрации Таро — колода Райдера — Уэйта (рисунки П. К. Смит, 1909), общественное достояние.

## Устройство проекта

```
put-zhizni/
  app/src/main/java/ru/putzhizni/app/   Kotlin: WebView, мост к JS, напоминания, шаги
  app/src/main/assets/www/              интерфейс (HTML/CSS/JS, без внешних библиотек)
    js/core.js        хранилище, навигация, формы
    js/data.js        модель данных, показатели, PRIME SCORE, корреляции
    js/v-*.js         экраны
    js/content-*.js   учебные материалы, книга, словари репетитора
    numerology.html   модуль нумерологии и Бацзы
```

Сборка: `./gradlew assembleRelease` (нужны JDK 17 и Android SDK 34), либо
автоматически в GitHub Actions при каждом изменении папки `put-zhizni/`.

Интерфейс можно открыть и в браузере: `app/src/main/assets/www/index.html`
через любой локальный веб-сервер.
